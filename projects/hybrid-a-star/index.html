Hybrid A*

Lightweight ROS 2 Hybrid A* planner for smooth, non-holonomic, collision-free paths — C++ core + Python visualization.

View source on GitHub All projects

Overview

In ROS 2 Humble, this package delivers a complete Hybrid A* planning pipeline: it generates occupancy maps and goal positions, computes smooth, collision-free non-holonomic trajectories using heuristic-guided motion primitives and path smoothing, and provides real-time visualization and animation of the planned path.
